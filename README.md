# Face Swap Prank App

A mobile app for real-time face swapping and fake video calls for entertainment purposes.

## Features
- Real-time face swap on photos and videos
- Fake video call simulation with celebrities or custom faces
- Built-in and user-uploaded face gallery
- Record and share pranks with watermark and disclaimer
- Age restriction and privacy-first design

## Setup
1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Clone this repo
3. Run `flutter pub get`
4. Add your own faces/videos/ringtones to `assets/`
5. Run on device: `flutter run`

## Notes
- For real-time face swap, native setup for MediaPipe/OpenCV may be required.
- All outputs include a watermark and disclaimer for ethical use.
- Age gate (13+) enforced at app start.

## Disclaimer
This app is for entertainment only. Do not use to impersonate or mislead others maliciously.
